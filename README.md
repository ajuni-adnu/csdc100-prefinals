## Short overview
This is my simple website made to inform you about GenAI.
* This website was made in cooperation for my CSDC100 prefinal.

> [!NOTE]
> This project utilized AI as a **tool**, although author still had to code the website and make this repository *manually*.\
> In the website, the left column is *pure human-input*. Right column uses actual *GenAI* answers for demonstration.

## Instructions on how to install or run the project

1. Clone the repository or download [.zip](https://github.com/ajuni-adnu/csdc100-prefinals/archive/refs/heads/main.zip) file.
```
git clone https://github.com/ajuni-adnu/csdc100-prefinals.git
```
2. Extract the zip package. Open the project folder, open `index.html`.

> [!TIP]
> Author also has the website online incase you ain't doing allat.\
> https://ajuni-adnu.github.io/csdc100-prefinals/
